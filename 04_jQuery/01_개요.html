        함수 모음집을 만들어서 배포했다.
        이것이 바로 jQuery라는 라이브러리인것이다!!!

        사람들이 많이 사용하는 JavaScript함수 모음집 == jquery

jQuery사용해보기

        우리는 jQuery를 사용해서 DOM요소 객체를 다룰 예정 

        jQuery코드가 문서상 모든 요소들이 전부 다 로드된 후에 실행할 수 있게끔 작업
        window.onload => 페이지가 전부 다 로딩되고 나서 자동으로 "딱 한 번" 수행
    
        - jQuery에서는 해당 내용을 세가지 구문으로 제공해서 해결
        
        1. 
        jQuery(document).ready(function(){
            실행하고 싶은 내용;
        });

        2. $: jQuery키워드를 나타냄
        $(document).ready(function(){
            실행하고싶은 내용;
        });

        3. $(fucntion(){
            실행하고싶은 내용;
        });
