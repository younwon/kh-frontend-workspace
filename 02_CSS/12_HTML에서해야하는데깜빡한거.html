시맨틱(Semantic)태그 == 의미가 있는 태그

        사람이 놓고보면 "아 여기는 머리, 여기는 본문"
        HTML만 놓고보면 전부다 똑같은 div
        구글봇 : 흠.. div가 있고 div가 있고 div가 있네
    
        div는 아무런 의미가 없어서 문제가 됨
        HTML5에서 의미 있는 태그 좀 쓰자해서 나온게 시맨틱 태그
        div에 의미달기

        쓰는 이유
        1. 가독성 => 태그명만봐도 뭔지 알겠음
        2. SEO(검색엔진 최적화) => 구글봇이 딱 보고 아 이거 이거 하고 이해함
        3. 웹접근성 => 스크린 리더 "메뉴입니다"하고 읽어줌

        기능은 div와 완벽하게 동일함 이름만 다름
