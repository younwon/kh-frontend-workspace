CSS(Cascading Style Sheets)
        HTML요소를 어떻게 보이게 할건지 지정하는 언어
        (색, 크기, 위치, 간격, 폰트, 애니메이션 등 전부~~)

        초창기에는 HTML에 스타일을 직접 기술
        => 구조(의미)랑 모양이 섞여서 유지보수 지옥 / 그래서 분리함

        HTML : 구조 / CSS : 모양 / JS : 동작

선택자(Selector)

문서상 "어떤 요소"에 스타일을 입힐지 고르는 문법
선택자로 원하는 요소만 골라서 스타일 부여

옛날 방식

1. 전체 선택자

        *{
            스타일속성 : 속성값;
        }
        color : 글자(Content) 생삭
        보통 문서 내 모든 요소 여백 초기화할 때 사용

2. 태그 선택자

        태그명 { 
            스타일 속성 : 속성값;
        }

3. 아이디 선택자

        #아이디속성값{

        }
        여기는 초록말고 다른색으로 하고싶은데??

4. 클래스 선택자

        .클래스속성값 {

        }
