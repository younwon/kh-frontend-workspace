이벤트

        * 용어 정리
        event          : 브라우저에서 발생하는 사건(클릭, 입력, 스크롤...등)
        event target   : 이벤트가 일어난 요소(button, div, input, ...등)
        event type     : 이벤트 종류(click, dblclick, mouseover, keydown, submint ...등)
        event listener : 이벤트를 감지하고 있다가 발생하면 Handler를 실행시키는 도구
        event handler  : 이벤트가 발생했을 때 실행할 코드 뭉치(함수)

        * 이벤트 거는 방법 3가지
        1. 인라인 이벤트 모델 => <요소 onclick="함수();">
        2. 고전 이벤트 모델   => 요소.onclick = 함수
        3. 표준 이벤트 모델   => 요소.addEventListener("type", 함수)
                                *권장사항 : 표준 이벤트 모델을 사용할 것

2. 고전 이벤트 모델

        요소의 이벤트 속성에 함수 대입 

        요소.onclick = () => { 어쩌고 };
        

        null대입하면 이벤트 제거됨

3. 표준 이벤트 모델 => addEventListener

        요소.addEventListener("event type", event handler);

        - 제거 : removeEventListener
